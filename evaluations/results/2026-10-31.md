# Smoke evaluation — 31 October 2026

## Setup and limits

Six independent Work Mode agent sessions received an isolated copy of the four installed skill files and one request each. Sessions started without the parent conversation. Their assigned inputs contained neither the rubric nor other test outputs. Requests used explicit skill invocation. Each case ran once, with no retries or revisions to the evaluated skill between cases.

The host inherited its active model configuration; an exact model build identifier, sampling settings, and seed were not exposed in this run record. The outputs below are the unedited final responses. Full internal tool traces are not archived here; grading is limited to the final answers, not independent verification of every internal action.

The author of the changes manually graded the outputs against [rubric.json](../rubric.json). This is a small, non-blinded smoke check, not an independent benchmark. There is no without-skill control, repeated sampling, or measured baseline improvement. Similar failure modes appear in the instructional examples; this checks application with changed inputs, not broad generalization.
